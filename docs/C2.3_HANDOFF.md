# 企鹅投研-凸性｜C2.3 实现与终验交接

状态：正式冻结；等待用户另行授权开发

## 1. 开始前

1. 完整读取 `AGENTS.md`、C2.3需求锁全部正式文件和继承的C2.2锁。
2. 重算哈希；不一致时停止，不按被修改的冻结文档实现。
3. 记录当前脏工作区，不覆盖候选生产修复、用户文件或正在运行的后台状态。
4. 只读记录正式快捷方式、8766服务、浏览器进程基线、调度器、候选生产PID/runId/断点和两库状态。
5. 安装所需开发工具时优先保证稳定与可重复构建；可安全自定义的SDK、缓存和工具优先放 `F:\DevTools`，系统共享组件保留默认系统位置。不得散放到 `F:\` 根目录。

## 2. 推荐实现顺序

### M1 构建基线

- 安装并锁定.NET 10 SDK和WebView2 SDK。
- 创建最小WPF容器和可重复Windows x64自包含构建。
- 先完成单实例、窗口记忆和WebView2独立数据目录自动测试。

### M2 服务生命周期

- 实现端口与健康身份检查。
- 实现自有服务精确PID、外部服务复用和未知端口保护。
- 证明启动与关闭不影响候选生产、筛选、跟踪和调度。

### M3 页面与故障恢复

- 加载现有桌面宿主，限制本地域，外部链接交给默认浏览器。
- 实现三个启动阶段和五类原生故障页。
- 实现页面进程恢复、打开日志和WebView2安装/修复。

### M4 正式入口与回滚

- 保留旧脚本作为隐藏回滚资产。
- 在隔离快捷方式上验证后，才切换唯一正式桌面快捷方式。
- 验证只恢复快捷方式即可回滚。

### M5 自测、独立终验和发布

- 按 `C2.3_TEST_STRATEGY.md` 选择受影响测试，不机械全量。
- 从正式快捷方式完成 `C2.3_ACCEPTANCE_PLAN.md` 的真实桌面路径。
- 对账继承资产、后台任务、数据库、文档和发布状态。

## 3. 禁止事项

- 不修改C2.2业务规则、阈值、页面内容、数据库结构或采集库保留策略。
- 不让C#读取第三方业务API、计算结论、直接写业务数据库或形成第二业务通道。
- 不通过名称、端口或通配符批量结束Python、Edge或Chrome进程。
- 不暂停、重启、重复启动或等待候选生产和Gate 0作为测试。
- 不建立第二个长期Windows调度器。
- 不删除旧桌面资产、历史数据或用户已有改动。
- 不开发网页版、移动端、钱包、自动交易或数据库压缩。

## 4. 测试纪律

- 每次测试先写明影响范围和扩大条件。
- 小改动先跑5分钟内快速反馈；受影响回归原则上20分钟内。
- 超过20分钟的测试必须独立运行、有进度、超时和结果文件。
- 先复现再修复；局部失败定点重验，不反复从头执行无关套件。
- 真实快捷方式和用户路径不能由无头截图、静态文件存在或实现报告替代。

## 5. 阶段门禁

冻结不授权编码。只有用户明确要求开始C2.3开发后才能安装SDK、创建容器或修改快捷方式。开发完成仍需按风险独立终验；全部发布门槛通过后才能更新C2.3发布状态。
