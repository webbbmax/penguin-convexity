# 企鹅投研-凸性｜C2.2 用语字典

状态：正式冻结

## 1. 固定页面名称

- 更新中心
- 90 天新币筛选
- 凸性跟踪更新
- 机会首页
- 全部机会
- 重要变化
- 我们如何判断

## 2. 固定生命周期用语

- `age_0_30`：0—30 天
- `age_31_90`：31—90 天
- A：新项目新币
- B：老项目新资产
- C：项目关系未确认
- D：只有代币，仅后台保留

生命周期用语不得附带“更优、更早、更有潜力”等质量暗示。

## 3. 固定跟踪状态

- `convexity_clue`：凸性线索
- `active_project`：活跃项目
- `observing`：观察中
- `awaiting_first_tracking`：等待首轮跟踪

“等待首轮跟踪”只表示尚无首份完整跟踪结果，不表示项目差、接口失败或需要人工批准。

## 4. 贝叶斯用语

允许：

- 动态贝叶斯证据评分
- 后验改善 / 稳定 / 减弱 / 尚无实测
- 独立可信度
- 当前结果更接近同组先验
- 时间外结果仍在积累

禁止：

- AI 预测上涨
- 算法已经越来越准
- 成功概率 / 收益概率
- 多少分等于凸性线索
- 贝叶斯证明项目靠谱

## 5. 数据和失败用语

前台允许：

- 数据截止到……
- 当前字段尚无可靠记录
- 保留最近一次完整判断

前台禁止把以下内容作为项目分类或醒目标识：

- 数据受限
- API 失败
- 额度耗尽
- 程序错误
- 配置缺失

上述内容只在后台使用，并严格区分 `no_data`、`quota_limited`、`source_failure`、`unsupported`、`configuration_missing`、`program_failure`。

## 6. 证据边界

- GitHub 单独满足产品证据：`仅代码证据；不证明产品部署、用户采用或投资价值。`
- C 类：`项目关系未确认；不冒充身份已核实。`
- T0：`已接入范围内目前可核验的最早公开流通证据。`
- 凸性线索：`符合冻结强证据路径；不表示安全、低估或值得买入。`
- 活跃项目：`近期存在可复算活动；不表示未来成功或上涨。`

## 7. 禁止投资责任用语

前台和后台均不得生成普通建仓、极限试仓、仓位比例、买入点、卖出点、目标价、保证退出或收益预测。旧版本历史字段可以为回滚保留，但不得重新进入 C2.2 普通前台。
