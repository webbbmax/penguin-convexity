## 1. 结论

C2.0 冻结范围已完成独立终验、缺陷修复、完整回归并发布。A-G 共 61 项验收全部通过；59 个 Python 测试脚本、29 个角色路由、31 个本地页面/资源、真实前后台点击路径、桌面启动与隐藏调度均通过。

后台左侧栏唯一版本号已更新为“当前版本 C2.0”；机会中心、项目详情和桌面宿主可见版本号仍为 0。需求锁中的 5 份正式文档和 5 个不可变核心研究文件哈希全部一致，未修改评分、动作、L0-L5、风险、剩余凸性、交易性、点火距离、生命周期规则或 SQLite 业务表。

## 2. 用户现在能看到什么

- 双击桌面快捷方式“企鹅投研-凸性”，首页仍直接进入凸性机会中心。
- 机会首页先显示当前结论、0 至 5 个真实有效信号、当前限制和实质变化；没有有效信号时显示真实零状态，不用模板补位。
- “全部机会”按“现在必须看 / 值得继续看 / 保持观察”排序，每个项目提供 1 至 3 条排序理由；阅读顺序不替代投资动作或 L0-L5。
- “重要变化”默认只显示可能改善或可能收紧判断的事件链；纯行情变化不升格，数值带单位、比较基准和数据时间。
- 项目详情以一个当前动作区加四个摘要区呈现五段式判断，并保留入口、筛选、页码和滚动位置。
- 工作台“模型与规则 → 判断质量”显示七类覆盖漏斗、质量指标、阻断排行和闭环队列，只提供现有安全处理入口，不新增研究写按钮。

## 3. Sol 终验修复

1. 修复全部机会的稳定阅读排序，使风险保护、动作变化、交易与退出、证据边界和时间顺序符合冻结口径。
2. 修复质量快照过早丢弃任务上下文的问题；闭环队列现在保留任务、最近执行、最近结果、复查时间和具体入口，溯源索引补齐原始事件与 lineage。
3. 修复首页卡片信息层级、正常状态误报、五段式详情布局、动态筛选后整卡点击与键盘导航、返回滚动恢复。
4. 修复变化页把内部模型枚举和分数字段误写成“证据成熟度”的问题；过滤 `machine_rule`、关注顺序分和错配分，统一动作显示语言，卖出路径内部状态改为用户可读文案。
5. 修复纯行情随整轮方向被升格、实质变化被数值标题覆盖、数值缺单位/比较时间的问题。
6. 修复科学计数法校验把随机构建标识误判为数值的非确定性失败，并增加连续构建与失败注入保护。
7. 修复详情页 `unknown`、`verified` 等底层英文枚举直出的显示问题，只在前台显示层翻译。
