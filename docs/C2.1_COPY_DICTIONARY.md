# C2.1 前后台用语字典

状态：正式冻结；等待实现；产品代码未开始  
适用版本：C2.1「90 天新发项目自动筛选与可解释前台」

## 1. 总原则

- 前台使用普通用户能直接理解的产品语言；后台保留来源、规则、游标、重试和错误分类。
- “通过硬门槛”只表示进入本产品的观察范围，不表示安全、靠谱、低估或值得买入。
- 事实、项目方陈述、规则结果和无法确认必须分开。
- 缺失、无数据、来源失败和不支持不得统一写成“资料不足”。
- C2.1 不显示投资动作、仓位、买卖点或收益概率。

## 2. 核心名称

| 机器字段 | 前台固定名称 | 必须同时说明 |
|---|---|---|
| `t0` | T0（目前查到的最早公开流通证据） | 只代表接入范围，发现更早证据时会修正 |
| `relationshipClass=A` | 新项目新币 | 项目和官方资产关系已建立 |
| `relationshipClass=B` | 老项目新资产 | 代币新发不等于项目刚成立 |
| `relationshipClass=C` | 项目关系未确认 | 不冒充身份已确认 |
| `relationshipClass=D` | 只有代币 | 只留后台，不进入前台 |
| `hardGate=pass` | 符合前台观察范围 | 不表示投资价值或未来安全 |

## 3. 五种互斥状态

| 机器字段 | 前台名称 | 固定解释 |
|---|---|---|
| `data_limited` | 数据受限 | 关键数据暂时无法更新，当前不能形成完整判断；保留上次完整记录并显示时间 |
| `convexity_clue` | 凸性线索 | 已形成至少两条可复算强证据路径，其中包含交易与流动性；不是上涨预测 |
| `active_project` | 活跃项目 | 已出现真实活动，但尚未形成凸性线索；不表示靠谱、低估或安全 |
| `early_observation` | 新发观察 | 真实历史不足14天且尚未形成强/弱线索；不是等待期或年龄扣分 |
| `continuous_observation` | 持续观察 | 真实历史已满14天且仍符合前台资格，但尚未形成强/弱线索 |

状态优先级固定为：数据受限 > 凸性线索 > 活跃项目 > 新发观察 > 持续观察。

## 4. 四条强证据路径

| 机器字段 | 前台固定名称 | 禁止替代表达 |
|---|---|---|
| `trade_liquidity_formation` | 交易与流动性形成 | 市场认可、资金抢筹、确定可卖 |
| `verified_product_usage_expansion` | 真实产品使用扩张 | 用户爆发、采用确定增长 |
| `supply_demand_structure_improvement` | 供应与需求结构改善 | 代币经济优秀、供不应求 |
| `indexed_pool_activity_outpaces_supply_adjusted_valuation` | 已索引池活动超过供应修正估值变化 | 全池、全球全池、全市场成交 |

路径状态：

- `formed`：已经满足冻结规则。
- `forming`：真实比较窗口尚未形成，继续使用已经发生的数据。
- `not_formed`：数据完整但没有满足规则。
- `unavailable`：来源、历史或身份不足，不能计算；不得写成未达标或0。

## 5. 产品证据

| 证据 | 前台标签 | 边界文案 |
|---|---|---|
| 官方合格 GitHub 仓库 | 仅代码证据 | 目前只确认代码仓库，不证明产品部署、用户采用或投资价值 |
| 已验证产品合约 | 已部署产品 | 只证明合约已部署，不自动证明有真实用户 |
| 结构化业务数据 | 已有业务数据 | 显示指标、定义、时间和来源，不把项目方口径冒充独立事实 |
| 已执行代币功能 | 代币功能已执行 | 只说明链上功能已经发生，不评价经济价值 |
| 可复现产品使用 | 已有链上使用 | 地址不等于真实用户，激励或机器人活动仍可能存在 |

禁止把官网、白皮书、普通社交账号、粉丝数、Star、涨幅或普通转账单独写成产品证据。

## 6. 来源与失败

| 后台状态 | 前台表达 | 不能写成 |
|---|---|---|
| `no_data` | 当前来源没有返回这项数据 | 数值为0、项目没有资料 |
| `quota_limited` | 数据来源额度暂时受限 | 项目资料不足 |
| `source_failure` | 数据来源暂时连接失败 | 项目本身失败 |
| `unsupported` | 当前接入范围暂不支持 | 项目不存在、数据为0 |
| `configuration_missing` | 当前来源配置缺失，需要维护 | 项目风险 |
| `program_failure` | 本次处理发生程序错误，需要修复 | 项目异常、项目资料不足 |

前台只显示受影响字段、受影响项目、最近成功时间和当前影响；接口名称、账户额度、响应码、重试和游标只在后台。

## 7. 页面固定文案

### 机会首页

- 统计项：合格项目、24小时新增、凸性线索、活跃项目、数据受限、最后成功时间。
- 主区标题：`今天先看`。
- 有合格项目时：`以下项目均已通过前台观察门槛；状态表示证据进展，不是投资评级。`
- 合格项目为0时：`当前没有项目通过全部前台观察门槛。下面显示真实阻断分布，系统不会用模板项目补位。`

### 全部机会

- 标签：全部、凸性线索、活跃项目、新发观察、持续观察、数据受限。
- 默认说明：`这里展示全部通过前台观察门槛的项目，不按综合分隐藏。`

### 重要变化

每条必须回答：发生了什么、之前是什么、现在是什么、为什么影响判断、数据更新到什么时候。

### 我们如何判断

固定结尾：

> 本产品只能在已接入范围内自动形成研究线索，不能证明项目靠谱、市场低估、未来上涨或一定能够退出。最终投资判断仍由用户负责。

## 8. 禁止用语

- 靠谱项目、优质币、安全项目、已验证投资价值。
- 必涨、上涨概率、胜率、确定低估、稳赚。
- 全球首次流通、全市场覆盖、全球全池。
- 钱包用户数、真实用户数（只能写链上地址数或可检测地址）。
- 因年轻而更好、年龄加分、新鲜度分。
- 因接口失败而“资料不足”。
- 因综合分达到某值而“凸性线索成立”。

## 9. 桌面端边界

C2.1 普通用户文案不出现“移动端”“手机版”“手机适配”“平板适配”或移动端下载入口。本版本只交付现有 Windows 桌面产品。
