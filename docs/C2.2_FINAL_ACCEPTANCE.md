# 企鹅投研-凸性｜C2.2 第二轮独立最终验收

验收时间：2026-08-11

结论：C2.2 冻结范围 39/39 项通过；第二轮发现的三个发布级缺陷已修复并回归通过，版本可以发布。

## 本轮实际修复

1. C2.2 快照原先晚于 C2.0/C2.1 旧渲染器载入，详情返回和 `pageshow` 可能再次触发旧渲染器并访问不存在的控件。现已把 C2.2 快照前置，并让三个旧渲染器在 C2.2 页面不再接管渲染。
2. 桌面启动器原先可能把仍在运行的 C2.1 服务误判为当前版本。健康检查现同时核验 `experienceRelease=C2.2`、`/api/c2.2/status` 和 C2.2 页面资源。
3. C2.2 单实例锁原先用 `os.kill(pid, 0)` 探测 Windows 进程，存在误终止风险。现改为 Windows 原生只读进程句柄检查，并新增活锁拒绝、陈旧锁恢复测试。
