## 当前已知数据边界

- 5 个前台项目因路径四的“历史供应”或“已索引池 OHLCV”暂不可用而显示“数据受限”。受影响链为 Robinhood 与 Solana。
- 这 5 个项目的九项宽硬门槛均已通过；`stale` 表示关键数据时效受限，不表示硬门槛失败。
- 独立库来源健康记录仍如实保留 `no_data`、`source_failure`、`unsupported` 与 `configuration_missing`，没有互相冒充。
- T0 只代表接入范围内目前查到的最早公开流通证据，不代表全市场或全局最早时间。
- 路径四只声明已索引池范围，不声称全球全池；缺失输入不补零。
