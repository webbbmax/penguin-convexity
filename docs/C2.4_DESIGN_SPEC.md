# 企鹅投研-凸性｜C2.4 UI 与 UX 设计规格

状态：正式冻结  
目标用户：不需要理解代码、任务 ID、接口状态码或贝叶斯公式的普通用户

## 1. 设计原则

1. 先说结果，再说原因，最后展开计算依据。
2. 前台只讲机会、证据、风险、变化和数据时间；任务、来源、额度、重试和日志只在后台。
3. 红色只用于真实故障、硬交易阻断或严重异常；正常零结果和能力边界使用中性样式。
4. 同一业务对象不在一个页面混入两套数据生产者或两个截止时间。
5. 不用大量数字和技术标签替代解释；每个数字必须有名称、范围和截止时间。
6. 保留 Logo、口号“洞见共识之外的价值”和南极蓝视觉；C2.4 是主干扩展，不是新产品壳。

## 2. 前台导航与页面结构

顶级导航固定为：机会首页、全部机会、重要变化、我们如何判断。项目详情不进入顶级导航。工作台只通过右上角低干扰入口进入。

### 2.1 机会首页

首屏顺序：

1. 一句话说明当前公开结果和数据截止时间。
2. 公开总数及“凸性线索、活跃项目、观察中”三类数量。
3. “按链看重点”链选项。
4. 当前链最多 10 张真实项目卡。
5. 进入当前链“全部机会”的明显入口。

链选项必须同时显示链名和公开数量。0 数量也显示，但不给错误色。一次只激活一条链。

项目卡固定层次：项目名/链/生命周期 → 当前公开状态 → 为什么现在关注 → 关键证据 → 最大风险或反证 → 下一观察项 → 数据截止时间。90 天后项目必须显示“已公开流通第 N 天”。

首页不得出现任务进度、来源故障、待跟踪、接口枚举、裸贝叶斯分数和跨链名次。

### 2.2 全部机会

- 链筛选放第一层，生命周期、A/B/C 和公开状态放第二层。
- 固定 20 条分页，显示当前筛选结果总数和页码。
- 90 天内与 90 天后持续跟踪使用清晰标签和可单独筛选的列表，不把年龄写成好坏。
- “全部链”模式不显示跨链贝叶斯名次。
- 空状态必须说明“当前筛选条件下没有完成第二关并达到公开底线的项目”，不得暗示程序故障。

### 2.3 重要变化

- 顶部固定链筛选与生命周期筛选。
- 每条变化以“发生了什么 / 为什么重要 / 下一步观察”三段展示。
- 时间是排序主轴，项目与链是辅助信息。
- 不展示任务日志、来源错误和普通价格流水。

### 2.4 判断说明与详情

“我们如何判断”默认使用大白话；高级说明折叠公式和来源独立规则。项目详情首屏必须能让用户不展开任何技术模块也理解项目为什么进入、当前状态和失效条件。

外部 HTTP/HTTPS 链接由 Windows 默认浏览器打开。软件内保留原页面，返回时恢复筛选、页码和滚动位置。

## 3. 后台信息架构

左侧栏固定七组：

1. 工作台概览
2. 更新中心
3. 候选与项目
4. 证据与来源
5. 持续跟踪
6. 判断规则与质量
7. 系统设置与日志

业务版本号只在后台左栏底部显示一次。一个入口只有在使用当前 C2.4 数据、数量和用语并通过真实验收后才可见；其余按正式继承清单保留为上下文入口、明确替换或保留未启用。

## 4. 更新中心交互

“90 天候选初筛”和“凸性跟踪”必须是两个独立页面，不使用同一张混合任务卡。

每页从上到下固定为：

1. 这项更新会更新什么。
2. 当前模式：仅手动或自动频率。
3. 主操作：立即更新；运行中改为“正在更新”。
4. 暂停新周期、继续上次未完成。
5. 当前进度、阶段、完成/总数、最近心跳。
6. 最近成功、下一次自动运行。
7. 本页来源状态，按“正常 / 能力边界 / 需要处理”分组。
8. 真正可恢复的失败项提供“只更新这个来源”。

按钮点击后 1 秒内必须出现确认状态；长任务持续显示原子进度和心跳。重复点击不得启动第二实例。没有可执行操作的能力边界不得伪装成错误按钮。

## 5. 状态颜色与普通语言

- 蓝/南极蓝：当前选择、正常进行、普通信息。
- 绿：最近一次成功完成。
- 灰：正常无新增、无数据、当前不支持或尚未到期。
- 橙：额度冷却、连接重试、后台观察等需要等待但未造成数据破坏的状态。
- 红：程序失败、配置缺失导致现役链路中断、确认硬交易阻断、严重异常或必须用户处理的故障。

任何红色区域必须回答：哪里出错、影响什么、会不会自动恢复、用户现在能做什么。不能只显示状态码或条数。

## 6. 桌面体验

- 正式桌面入口继续使用 C2.3 `.NET 10＋WPF＋WebView2` 容器。
- 启动、单实例、窗口记忆、故障恢复、外部浏览器隔离和隐藏本地服务全部继承。
- 后台长任务不弹黑框；关闭软件不停止独立后台任务。
- 本版本只验收 Windows 桌面 1180×760 和 1440×900/最大化，不开发移动端布局。

## 7. 可访问性与防误操作

- 链选项、分页、筛选和折叠项支持键盘焦点与可读标签。
- 不以颜色作为唯一状态区别。
- 破坏性或会改变运行状态的操作必须有明确文字；普通阅读路径保持只读。
- 真实桌面验收不得点击会启动全量更新、改频率或暂停任务的按钮，除非该验收已获得专门授权并使用隔离环境。
