# C2.1 页面与数据契约

状态：正式冻结；等待实现；产品代码未开始  
适用版本：C2.1「90 天新发项目自动筛选与可解释前台」  
规则配置：`docs/C2.1_RULE_CONFIG.json`

## 1. 页面清单

### 前台

| 页面 | 角色 | 数据范围 |
|---|---|---|
| 机会首页 | public | 统计带、今天先看、五状态计数、前台数据健康 |
| 全部机会 | public | 全部硬门槛通过项目、标签、筛选、分页、排序 |
| 重要变化 | public | 会改变资格、证据、状态、可信度或退出的变化 |
| 我们如何判断 | public | 规则、来源、边界与不能得出的结论 |
| 项目详情 | context | 单项目资格、证据、状态、历史、风险、数据时间 |

### 后台

不新增 HTML 路由或后台一级栏目。C2.1 只在以下现有路由中增加冻结内容：

| 现有路由 | C2.1 固定职责 |
|---|---|
| `workbench.html` | 后台壳与七个一级栏目，不承载业务细节 |
| `update-center.html` | 立即更新、仅手动/自动频率、暂停、单实例运行、断点和恢复进度 |
| `project-master-pool.html` | 90 天候选、T0、A/B/C/D、宽硬门槛漏斗与 D 类后台保留 |
| `source-discovery.html` | 接入链/DEX/来源范围、可能漏项和未支持范围 |
| `source-registry.html` | 来源状态、额度、重置时间、失败原因和影响对象 |
| `data-backbone.html` | `c2.1-pipeline.db`、分片游标、历史回溯、快照构建和数据状态 |
| `rules-replay.html` | 规则版本、P60/P70、四路径、五状态、防抖与固定回归复算 |
| `decision-quality.html` | 五因子方向、独立可信度、字段覆盖和数据质量冲突 |

重试、额度、游标和任务控件只能出现在上述后台路由，不得放到前台。

## 9. 因子与可信度


## 11. 页面查询契约

### 全部机会

```text
state=all|convexity_clue|active_project|early_observation|continuous_observation|data_limited
ageBand=all|0_30|31_90
relationship=all|A|B|C
chain=all|<chainId>

dataStatus=all|healthy|limited|interrupted
sort=system|latest_change|t0_desc|liquidity_desc|volume_desc

```

`pageSize` 固定 20，不接受无限滚动替代分页。

## 12. 排序契约

`system` 排序可以使用内部贝叶斯分数、变化重要性、数据可信度和风险护栏，但必须输出 `sortReason`。排序不能改变状态、硬门槛或前台资格。

## 13. 前后台隔离

前台禁止：

- API 密钥、账户额度标识、请求正文、任务 ID、游标、重试控件。
- 五因子内部数值和“总分达到某值所以是凸性线索”。
- 未经规则转换的异常栈、枚举和科学计数法。
- 人工通过、退回、发布按钮。

后台必须保留完整输入、公式版本、来源、失败原因、额度账本、回溯游标、算法复算和历史版本。

## 14. 快照失败保护

- 构建失败沿用上一份完整快照并明确标记生成延迟。
- 任何硬门槛通过项目在新快照中静默消失时，整次前台快照构建失败。
- 新旧快照必须原子替换并共享 `buildId`。
- 原始事件、日聚合和历史状态不得因前台失败被删除或覆盖。

## 15. 阈值与防抖契约

每次项目规则结果必须保存：

```text
ruleVersion
ruleConfigHash
cohortSnapshotId
cohortScope
cohortSampleSize
entryThresholds
exitThresholds
evaluationWindowId
consecutiveCompletedMisses
formedAt
invalidatedAt
```

- 进入允许在第一个完整评估窗口形成后发生。
- 正常退出需要两个新的连续完成窗口均低于退出规则；同一窗口重复运行不能增加次数。
- 硬门槛失败、第 91 天和已确认严重异常立即退出。
- `quota_limited`、`source_failure`、`unsupported`、`configuration_missing`、`program_failure` 不算一次正常未通过。

## 16. 桌面端数据展示边界

- C2.1 只交付 Windows 桌面产品。
- 页面数据契约不定义手机端、平板端、移动端卡片或移动端字段裁剪。
- 1180×760 与 1440×900/最大化窗口必须显示同一核心字段和相同判断，不允许因窗口尺寸隐藏项目或改变状态。
