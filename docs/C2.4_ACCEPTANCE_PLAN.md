# 企鹅投研-凸性｜C2.4 独立验收计划

状态：正式冻结  
发布原则：核心合同优先；实现报告、测试耗时和用例数量都不能替代独立证据。

## A. 冻结与继承

- A01：`docs/C2.4_REQUIREMENTS_LOCK.json` 中全部正式文件哈希匹配。
- A02：C2.2、C2.3、模型协议、测试优先级和临时产物策略依赖哈希匹配。
- A03：29 个既有路由均在正式继承清单中且每项只有一种处理。
- A04：批准删除数为 0；没有页面、数据或回滚资产被静默删除。
- A05：C2.3 桌面容器、本地 HTTP 单一通道、唯一调度器和两个独立作业保持。

## B. Tier 0 核心集合

- B01：从底层只读数据独立重算第一关通过集合。
- B02：每个当前 90 天内跟踪对象都能追溯到第一关通过，绕过数为 0。
- B03：公开对象全部有最新完整第二关结果，绕过数为 0。
- B04：“全部机会”与公开快照逐 `assetId` 完全相等。
- B05：公开快照是跟踪快照子集，差集为 0。
- B06：首页每链数量不超过 10，且是完整公开快照的只读派生。
- B07：固定同链第 11 名不在首页，但仍在跟踪、公开快照和全部机会。
- B08：无完整贝叶斯结果的公开项目不在首页，但仍在全部机会。
- B09：两个生命周期池和三种公开状态互相独立，组合计数可复算。
- B10：所有集合去重 `assetId` 数等于记录数；重复数为 0。
- B11：前台、后台和快照在同一截止时间的总数、各链数、池数和状态数一致。

## C. 第一关

- C01：日龄 0 和 90 在其他四项满足时通过；91 不再进入当前候选池。
- C02：链、合约、池、方向或稳定 `assetId` 不可确定时不通过。
- C03：至少 1 笔真实买入和 1 笔真实卖出；任一缺失不通过。
- C04：确认冻结、黑名单或无法卖出立即不通过。
- C05：A/B/C/D、项目证据、金额、流动性、成交额、报价、风险/供应返回、贝叶斯和强路径均不控制第一关。
- C06：风险未知进入等待第二关，不写成安全或失败。
- C07：D 类可进入后台跟踪工作清单，但不能进入公开快照。

## D. 公开底线与状态

- D01：没有新完整可复算结果不得公开。
- D02：风险来源必须成功且无硬阻断/严重异常。
- D03：100 美元卖出损失 15% 正常公开；大于 15% 且小于 20%只在后台；20%及以上立即撤下。
- D04：至少一条可归属项目证据；GitHub 单独证据显示固定边界。
- D05：T0、方向或 `assetId` 失效不得公开。
- D06：公开对象只属于凸性线索、活跃项目、观察中之一，互斥且合计一致。
- D07：待首轮、D 类、来源重试、缺证据、报价不足和风险未完成不进入机会中心。
- D08：凸性线索为 0 时，合格活跃项目或观察中仍正常显示；不得伪造线索。

## E. 四路径、贝叶斯与防抖

- E01：交易需求路径按 P50、买卖和异常规则复算。
- E02：流动性/退出路径按 P50、固定美元护栏、10%报价和 80%崩塌规则复算。
- E03：供应/持币路径按 2 个百分点、5%、0.25%及成交额 P40 复算。
- E04：第四路径只汇总提供方已索引且有可比历史的池，按相对扩张 P50、正风险调整剩余、供应单位和异常复算。
- E05：缺失、失败、单位冲突和不可比窗口为不可用，不变成 0 或未形成。
- E06：两路径、必含交易/流动性之一、两类独立来源和市场数据防重复计数全部满足后才形成凸性线索。
- E07：总分、价格、成交额或代码仓库不能单独形成凸性线索。
- E08：一份新完整窗口可进入；两个不同新完整窗口才正常退出；重复同窗口不累计。
- E09：确认硬阻断、严重异常或卖出损失 20%立即退出。
- E10：贝叶斯五因子权重为 25/25/20/15/15，总分不控制第一关、公开资格或线索。
- E11：同链排序按后验、可信度、有效指标、最近时间、`assetId`；不存在跨链总榜。
- E12：P50/P40 动态比较组和固定后备值与规则配置一致，样本不足时显示实际回退组和样本量。

## F. 第 91 天迁移

- F01：有 0—90 天第一关、完整跟踪、公开底线和有效身份历史的同一 `assetId` 迁移到 `continued_91_plus`。
- F02：从未完成两关或从未公开合格的对象不迁移。
- F03：迁移不复制记录，不返回第一关，不占新候选数量。
- F04：持续跟踪显示准确日龄，年龄不改变分数或状态。
- F05：正常退出用两个新窗口；硬阻断、严重异常和 20%报价立即撤下。
- F06：发布迁移只读本地历史，不重扫老项目、不重跑 Gate 0。

## G. 前台真实用户路径

- G01：首页首屏数量、三状态和截止时间正确。
- G02：六链选项来自正式链目录，0 数量也显示。
- G03：每链两个生命周期池合计最多 10 张真实卡，不是各 10 张。
- G04：每张卡回答固定五问，并显示链、状态、日龄和生命周期。
- G05：全部机会为全部公开项目、20 条分页，链/池/A-B-C/状态筛选正确。
- G06：重要变化链与生命周期筛选正确，详情返回恢复筛选、页码和滚动。
- G07：项目详情先讲进入理由、状态理由和失效条件；缺失模块不补模板或 0。
- G08：判断页普通层和高级层边界正确。
- G09：外部链接在 Windows 默认浏览器打开，应用上下文保留。
- G10：前台不出现任务、来源、重试、版本号、状态码或“数据受限”项目分类。

## H. 更新中心与恢复

- H01：两个更新页面、设置、按钮、进度、来源和脚本入口独立。
- H02：立即更新、暂停新周期、继续断点、最近心跳、最近成功和下一次运行可见。
- H03：能力边界与需要处理分组正确；红色只用于真实故障或硬风险。
- H04：可恢复失败提供同作业内单来源重试；正常无数据/不支持不提供误导操作。
- H05：重复点击不启动第二实例；手动与自动走同一恢复入口。
- H06：连接失败按冷却重试并从游标继续，不重扫 459 万历史母池。
- H07：后台隐藏运行，无黑框；操作一页不改变另一页设置。
- H08：原子快照失败保留上一份完整结果。

## I. 数据、桌面与临时产物

- I01：`data/convexity.db` 与采集库只读完整性检查通过，外键无异常。
- I02：正式快捷方式冷启动、重复启动单实例、窗口记忆和关闭重开通过。
- I03：1180×760 与 1440×900/最大化核心页面无整页水平溢出。
- I04：关闭应用不停止独立后台任务；候选生产和唯一调度器不被重启。
- I05：规则/页面测试没有复制多份完整采集库。
- I06：临时产物只进入登记专用区，正式数据库、备份、Gate 0 和发布资产不在自动删除范围。
