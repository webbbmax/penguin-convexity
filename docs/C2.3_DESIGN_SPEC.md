# 企鹅投研-凸性｜C2.3 桌面设计规格

状态：正式冻结

## 1. 视觉继承

Logo、口号“洞见共识之外的价值”、南极蓝、现有前后台信息架构和页面布局全部继承。C2.3 不重设计网页内容，不新增桌面专属导航，不在前台显示版本号。

## 2. 容器窗口

- 窗口标题：`企鹅投研-凸性`。
- 默认首次启动最大化；非首次恢复上次可见位置和大小。
- 容器只承载现有 `desktop/index.html`，不重复显示品牌栏、导航栏或状态栏。
- 最小支持视口 1180×760；同时验收 1440×900 与最大化。不做移动端布局。

## 3. 启动页

窗口出现后立即显示 Logo、产品名和当前阶段：

1. 检查本地服务
2. 启动本地服务
3. 加载产品页面

阶段只向前推进。超过正常时间显示已等待时间和真实阶段，不显示假百分比。

## 4. 原生故障页

- 标题说明发生了什么，例如“本地服务没有启动”。
- 一句话说明影响，例如“当前无法读取本机项目数据，后台扫描未停止”。
- 主按钮只提供当前有效动作：重新检测、重试启动、重新加载、安装/修复 WebView2。
- 次按钮可打开日志位置或折叠技术详情。
- 不显示 `Null`、原始堆栈、乱码、原始 JSON、任务内部 ID 或密钥。

## 5. 浏览器隔离

软件没有地址栏、标签页和通用下载入口。外部链接在默认浏览器打开；普通 Edge 和 Chrome 的窗口、进程、登录状态与插件不得被软件改变。

## 6. UX 验收

- 热启动5秒内可操作；冷启动30秒内进入产品或故障页。
- 第二次双击2秒内唤醒当前窗口。
- 空白页持续时间为0；用户始终能看到阶段或故障。
- 关闭软件后没有残留企鹅投研窗口或失控的WebView2会话；后台业务任务按原状态继续。
