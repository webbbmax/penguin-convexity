# C2.5 整版开发自测

结论：C2.5 实现候选已完成开发自测，79 项实现阶段需求具备代码、测试和证据；13 项独立终验需求仍保持 `pending`。本文件不构成独立终验或发布结论，当前正式产品仍为 C2.4。

## 基线与边界

- 从正式基线 `becd256b170b0a3a1a45de0b8c4f4a426eb9065a` 建立独立 `codex/c2-5-manager-control-plane` worktree；开发入口门禁已通过。
- C2.5 需求锁与 12 份冻结正式文件未修改；C2.4 的 29 个路由批准删除 0。
- worktree 未引入正式数据库、业务快照、凭据或运行状态；正式 main 在只读探针前后保持干净且提交未变。
- 未改桌面 C# 容器、正式快捷方式、正式 Windows 调度器、正式数据库、用户设置和现役作业状态。

## 实现范围

- 建立 41 项管理任务账本：20 项顶层入口与 21 项按需任务；独立枚举 Windows 任务、隐藏 VBS 下游、20 个继承 POST 接口和任务目录，遗漏 0、重复 0。
- 建立真实状态组合、来源与链健康、规则基线/活动覆盖/同输入重放、assetId 判定追踪、快照交接、运行记录与管理审计。
- 建立预览、确认、执行、权威回读两阶段控制；确认令牌有效期 5 分钟且单次使用，重复 requestId 不重复启动。
- 审计意图必须先成功落盘才能调用后台；最终审计失败会返回 `executing_unknown`，同一请求仍禁止二次执行。
- 新增 11 个后台承载页，后台归为 8 个信息域；普通用户前台继续与任务、调度、日志和控制分离。
- 落地统一设计令牌以及按钮 7 态、进度 7 态、反馈 5 态夹具；浏览器实现级检查发现并修复侧栏、顶栏和任务托盘布局问题。

- 部分旧静态测试仍硬编码 C2.4 的 7 个后台分组、C2.4 版本文案、旧 HTML 页数或 C1.7 文案；C2.5 冻结要求为 8 个信息域、后台唯一显示 C2.5，并新增 11 个页面，因此这些旧断言不作为候选失败依据。
