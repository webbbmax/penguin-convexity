# 企鹅投研-凸性｜C2.3 桌面容器契约

状态：正式冻结

## 1. 组件所有权

| 组件 | 唯一职责 | 禁止职责 |
|---|---|---|
| WPF 容器 | 主窗口、启动阶段、单实例、窗口记忆、WebView2 环境、故障与恢复 | 研究规则、业务评分、第三方采集、业务数据库写入 |
| WebView2 | 显示现有本地页面、隔离浏览器数据、控制导航 | 复用普通 Edge/Chrome 配置、充当通用浏览器 |
| Python 本地服务 | 8766 页面、静态资源、健康接口和现有业务 API | 控制 WPF 窗口或普通浏览器 |
| Windows 调度器与生产进程 | 新币筛选、凸性跟踪、候选生产、断点和恢复 | 依赖桌面窗口存活 |

## 2. 固定端点

- 首页：`http://127.0.0.1:8766/desktop/index.html`
- 健康检查：`http://127.0.0.1:8766/api/health`
- 端口：`8766`
- 健康响应必须同时匹配本项目产品身份、迁移版本、数据主干和当前体验版本；只监听端口不视为本项目服务。

## 3. 单实例

- 使用 Windows 用户会话级单实例锁。
- 第二次启动通过明确的进程间激活信号唤醒现有窗口；不得通过枚举普通浏览器标题寻找窗口。
- 激活超时必须给出可记录的错误，不得静默创建第二个实例。

## 4. 服务所有权

- 已存在且健康身份匹配的 8766 服务属于外部已运行实例，容器只复用，不停止。
- 容器启动的本地页面服务记录精确 PID、启动时间和脚本绝对路径。
- 容器关闭只处理自己记录的页面服务 PID；不得按 `python.exe` 名称、端口模糊匹配或目录通配符批量结束进程。
- 候选生产、新币筛选、凸性跟踪和 Windows 调度任务永远不属于容器子任务。
- 启动超时或容器崩溃不能清除后台锁、游标、断点、状态或数据库。

## 5. WebView2 环境

- 运行时：Evergreen WebView2 Runtime，启动前检测可用版本。
- 用户数据目录：本项目 `runtime/webview2/user-data`，必须可写且不得位于网络路径。
- 该目录只包含 WebView2 缓存、Cookie、权限和本地存储；不得存放数据库、业务快照、后台断点或密钥。
- 清理或重建用户数据目录前必须关闭本容器全部 WebView2 会话；不得触及普通 Edge/Chrome 数据。

## 6. 导航与原生能力

- 容器内只允许本项目 `http://127.0.0.1:8766` 导航。
- 用户主动点击外部 HTTP/HTTPS 链接时交给 Windows 默认浏览器。
- 非用户触发的外部导航、新窗口和下载默认阻止并记录。
- C# 原生能力只允许：窗口控制、服务启停、运行环境检测/修复、重新加载、打开日志目录、打开外部链接。
- 页面业务取数、业务判断、更新按钮和任务控制继续通过现有 HTTP API；不得为同一业务增加 C# 第二通道。

## 7. 窗口状态

- 保存 Left、Top、Width、Height、Maximized 和最后有效保存时间。
- 不保存最小化尺寸；最小可恢复尺寸为 480×360。
- 显示器变化或窗口落在可见区域之外时，回到主屏工作区中央。
- 窗口状态写入本项目运行目录并原子替换，不写 F 盘根目录或其他项目。

## 8. 构建与发布

- 目标：Windows x64、`.NET 10 LTS`、WPF、自包含部署。
- SDK 和 NuGet 版本必须锁定并记录；构建产物不得依赖开发机已安装的旧 .NET 6/7。
- WebView2 缺失或损坏时提供微软官方 Evergreen 安装/修复；离线场景提供官方离线说明。
- 正式快捷方式只指向新容器；旧 PowerShell 启动器保留为一个版本的隐藏回滚资产。

## 9. 可观测性

- 容器日志记录启动阶段、耗时、WebView2版本、端口身份、服务所有权、精确 PID、页面恢复和退出原因。
- 不记录 API 密钥、浏览器资料、完整业务响应或敏感请求头。
- 用户界面显示大白话，技术字段在后台日志或折叠详情中。
