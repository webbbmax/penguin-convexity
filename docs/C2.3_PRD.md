# 企鹅投研-凸性｜C2.3 正式产品需求

状态：正式冻结  
版本名称：C2.3「稳定桌面容器与浏览器隔离」  
冻结日期：2026-08-12（Asia/Shanghai）

## 1. 目标

C2.3 只替换 C2.2 当前由 PowerShell 调起普通 Edge `--app` 窗口的桌面容器，交付由 `.NET 10 LTS＋WPF＋WebView2` 管理的独立 Windows 软件窗口。目标是提高正式桌面入口、窗口生命周期、浏览器隔离和故障恢复的可靠性，不重做产品，不改变研究判断与数据流水线。

## 2. 用户结果

- 桌面继续只有“企鹅投研-凸性”一个正式入口，名称、Logo 和口号不变。
- 用户同时使用 Chrome 或普通 Edge 时，企鹅投研不得读取、复用、枚举、关闭或修改这些浏览器的窗口、标签、账号、Cookie、插件和个人配置。
- 双击入口后立即出现企鹅投研自己的软件窗口，显示启动阶段；不得先出现黑框、空白窗口或不可理解的技术异常。
- 重复双击唤醒已有窗口，不创建第二个容器、第二个本地服务或第二个后台作业。
- 关闭、重开或更新桌面容器，不影响候选生产、新币筛选、凸性跟踪、Windows 调度器及其 PID、断点、游标和进度。

## 3. 唯一主干与继承

C2.3 完整继承 C2.2：

- 前台四栏目、上下文详情与返回状态。
- 后台七栏目、两个独立更新页面、手动更新、自动频率、暂停、进度、来源归属和单项重试。
- T0、A/B/C/D、宽硬门槛、贝叶斯、四条强路径、风险、交易性、重要变化与全部冻结数值规则。
- `data/convexity.db`、`data/c2.1-pipeline.db`、原子快照、历史记录、游标、断点和用户设置。
- `127.0.0.1:8766` 本地服务、唯一 `PenguinConvexity-C1.8-Scheduler` 和现有独立后台作业。

本版本批准替换的对象只有桌面启动器、窗口管理和桌面故障恢复。批准删除的业务功能为零。

## 4. 技术决策

- Windows x64 桌面容器使用 `.NET 10 LTS＋WPF＋WebView2 Evergreen`。
- 正式发布采用自带 `.NET` 运行环境的部署方式，用户无需预装匹配版本的 `.NET`。
- WebView2 使用本项目独立用户数据目录，不共享普通浏览器配置。
- 现有 HTML、CSS、JavaScript 页面继续由 WebView2 加载；业务数据继续只从本项目本地 HTTP 接口读取。
- 保留 HTTP 的原因是现有桌面产品已经形成单一、可测试的业务通道，迁移时不重写可减少新增故障，不是为了约束未来网页版。
- C# 可以负责窗口、进程、启动阶段、运行环境修复、打开日志和服务恢复；不得计算业务分数、调用第三方业务 API、直接写业务数据库或形成第二套业务取数通道。
- 未来网页版单独立项，可以复用或重写当前实现，不构成 C2.3 的设计和验收约束。

## 5. 启动与退出

1. 容器先显示本地启动窗口。
2. 检查 8766 端口和 `/api/health` 的产品身份；未知占用不得被强制终止。
3. 健康服务直接复用；服务不存在时隐藏启动当前 `scripts/serve_local.py`。
4. 服务就绪后加载 `/desktop/index.html`；超时进入原生故障页，不无限等待。
5. 容器只管理自己创建的 WebView2 子进程和本地页面服务。复用的外部本项目服务、Windows 调度器和后台生产进程均不归容器退出流程所有。
6. 容器自行创建的本地页面服务在软件关闭时应先正常终止；无法正常终止时只能处理记录在本次容器会话中的精确 PID，不得按名称批量结束 Python。

## 6. 性能与状态

- 热启动：3 秒内显示窗口，5 秒内可操作。
- 冷启动：3 秒内显示窗口和阶段，30 秒内进入首页或明确故障页。
- 重复启动：2 秒内唤醒已有窗口。
- 阶段固定为“检查本地服务、启动本地服务、加载产品页面”。
- 磁盘或数据库维护导致超时时显示真实阶段，不伪装完成。

## 7. 故障分类

必须独立识别：WebView2 缺失或损坏、Python 本地服务失败、8766 被未知程序占用、本项目服务健康失败、WebView2 页面进程异常。用户看到大白话原因、影响、重试或修复入口；技术详情折叠显示。故障不得变成前台项目“数据受限”。

## 8. 测试原则

测试按实际改动风险分层，不以用例数量或耗时证明质量。开发中运行受影响测试；未修改业务资产通过冻结哈希、契约和快速冒烟证明继承；只有共享核心、规则、数据库、调度或影响边界不明时升级全量回归。C2.3 发布重点是真实快捷方式、冷/热启动、单实例、浏览器隔离、后台任务独立、窗口恢复、故障处理和回滚。

## 9. 程序上限

- WebView2 可以消除普通 Edge 窗口复用、标题识别和进程误判，但不能保证 Windows、微软运行时、安全软件或硬件永不故障。
- C2.3 不解决第三方 API、数据缺失、候选扫描速度、数据库膨胀和业务规则问题。
- WebView2 缺失且电脑离线时需要官方离线安装包。
- 关机仍会停止本机任务，开机恢复沿用既有 Windows 调度和断点规则。

## 10. 不在范围

不修改筛选、凸性跟踪、贝叶斯、强路径、项目分类、前台文案和投资判断；不清理或压缩采集库；不新增 API、链、DEX、来源、付费服务或调度器；不开发网页版、移动端、macOS、Linux、登录、云同步、钱包或自动交易；不重设计现有页面。

## 11. 阶段门禁

本文件冻结不授权产品编码。只有用户另行明确授权开始 C2.3 开发后才能修改产品代码、安装开发依赖和构建容器。开发自测不能替代按风险独立终验；发布前必须完成正式快捷方式切换和可回滚验证。
