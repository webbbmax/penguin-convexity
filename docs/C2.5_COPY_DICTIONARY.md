# 企鹅投研-凸性｜C2.5 用语字典

状态：正式冻结

## 1. 产品与入口

| 机器/旧名称 | 用户可见名称 | 说明 |
|---|---|---|
| `PenguinConvexity-C1.8-Scheduler` | 当前统一自动更新调度器 | 机器名保留，必须说明它当前调起 C2.2/C2.4 现役编排器 |
| `screening` | 90 天新币筛选 | 独立现役作业 |
| `convexity_tracking` | 凸性跟踪 | 独立现役作业 |
| `candidate-production` | 候选生产与历史续跑 | 包含日常增量和已授权历史队列 |
| `temp_artifact_retention` | 临时产物保留检查 | 同一调度入口下的维护检查 |
| C1.8 / C2.1 | 旧版兼容入口 | 不得称为当前自动主干 |
| Gate 0 | 已停用的一次性历史工具 | 禁止写成“待运行” |

## 2. 生命周期分类

| 机器值 | 中文 |
|---|---|
| `scheduled_active` | 自动启用 |
| `manual_on_demand` | 手动/按需 |
| `active_component` | 现役内部组件 |
| `legacy_callable` | 旧版仍可执行 |
| `dormant_compatibility` | 旧版兼容/休眠 |
| `disabled` | 已停用 |
| `completed_one_off` | 已完成的一次性任务 |
| `startup_automatic` | 服务启动时自动检查 |
| `service_component` | 桌面服务组件 |

## 3. 实时状态

| 机器值 | 中文 | 必须说明 |
|---|---|---|
| `not_started` | 尚未运行 | 不是失败 |
| `waiting` | 等待运行 | 等待条件或到期时间 |
| `launching` | 正在启动 | 尚未证明业务步骤运行 |
| `running` | 正在运行 | 显示进程/锁与心跳 |
| `pause_requested` | 已请求安全暂停 | 显示预计安全点 |
| `safe_paused` | 已在安全点暂停 | 显示检查点 |
| `partial` | 本轮部分完成 | 显示保留结果和剩余范围 |
| `completed` | 本轮已完成 | 显示完成时间和产物 |
| `failed` | 本轮失败 | 显示上一份完整快照是否可用 |
| `blocked` | 被条件阻断 | 显示阻断条件 |
| `stale` | 状态已过期 | 不代表当前运行 |
| `disabled` | 已停用 | 显示批准和原因 |
| `unknown` | 当前无法确认 | 显示缺少的依据 |

## 4. 来源状态

继续使用：成功、无适用数据、额度受限、来源失败、当前不支持、缺少配置、程序失败。真实零结果使用“本轮真实为 0”，不写“暂无机会”掩盖来源问题。

## 5. 控制按钮

| 操作 | 固定文案 |
|---|---|
| 立即执行 | 立即运行〈任务名〉 |
| 恢复 | 从检查点恢复 |
| 当前安全暂停 | 安全暂停当前运行 |
| 停后续周期 | 暂停后续自动周期 |
| 恢复周期 | 恢复后续自动周期 |
| 频率 | 修改运行频率 |
| 来源重试 | 重试失败来源 |
| 分片重试 | 重试所选分片 |
| 查看 | 查看运行详情 / 查看影响范围 / 查看日志 |

禁止单独使用：`确定`、`处理`、`执行`、`开始全部`、`刷新全部`。

## 6. 控制反馈

- 已接受：`操作已由真实运行通道接受。`
- 等待安全点：`暂停请求已收到，将在当前步骤的安全点生效。`
- 已有运行：`已有写入任务正在运行，本次没有启动第二个任务。`
- 禁用：`当前不能执行：〈原因〉。`
- 权威拒绝：`操作未执行，当前状态保持不变。追溯编号：〈ID〉。`
- 部分完成：`本轮已保留成功结果，剩余范围将从当前检查点继续。`

## 7. 规则

| 名称 | 固定表达 |
|---|---|
| frozen baseline | 冻结基线 |
| effective rule | 当前有效规则 |
| active override | 当前生效的临时覆盖 |
| historical version | 历史版本 |
| rule replay | 规则重放 |
| unavailable | 当前数据未提供 |
| not applicable | 不适用 |

活动试行必须显示：`这是经批准的试行覆盖，不等于安全、质量或买入结论。`

## 8. 时间

- `状态更新时间：`
- `最后心跳：`
- `业务数据截至：`
- `快照生成于：`
- `页面读取于：`
- `Windows 下次检查：`
- `作业下次到期：`

禁止统称“更新时间”。

## 9. 空状态

- 真实为零：`按当前口径，本轮真实结果为 0。`
- 尚未运行：`该任务尚未产生第一次运行记录。`
- 无适用数据：`当前对象没有适用来源。`
- 状态陈旧：`这是一条过期记录，不能证明任务当前仍在运行。`
- 加载失败：`未能读取最新状态，下面保留的是上一份完整数据。`
- 已停用：`该入口已停用；不会由当前调度器执行。`
- 旧版可执行：`这是旧版仍可执行入口，不属于当前自动主干。`

## 10. 投资责任边界

继续使用：`系统只提供研究建议，不自动交易。`  
不得出现保证收益、自动买入、自动调仓或把规则通过写成投资结论的文案。

## 11. 版本号

用户可见 `C2.5` 只在管理者工作台左侧栏底部显示一次。普通用户前台、项目详情、页眉、页脚和桌面宿主不显示业务版本号。
