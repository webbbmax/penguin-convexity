# 企鹅投研-凸性｜C2.2 大白话冻结稿

状态：**用户已确认；正式权威以 `docs/C2.2_REQUIREMENTS_LOCK.json` 为准**  
版本名称：C2.2「主干继承与筛选—凸性跟踪闭环整合」  
确认日期：2026-08-11（Asia/Shanghai）  
用户授权原文：`按冻结稿冻结C2.2`

## 1. 一句话目标

C2.2 不再创造一套新产品，而是把已经开发完成的四代能力接成一个产品：C2.1 发现并初筛新币，C1.7/C1.8 持续跟踪，C2.0 负责解释，C1.9 负责统一展示。

## 2. 唯一产品主干

- C1.7/C1.8：项目库、证据、来源、市场、风险、交易性、催化和跟踪任务。
- C1.9：前后台分离、四个前台栏目、七个后台栏目、详情进入和返回。
- C2.0：重要变化、判断解释、证据链和数据质量表达。
- C2.1：90 天新币发现、T0、A/B/C/D、宽硬门槛、增量游标和可恢复采集。

以后每个版本必须先生成继承清单。未列入删除且未经用户明确批准的已有功能不得消失。

## 3. 两阶段职责

第一阶段“90 天新币筛选”负责发现、T0、日龄、A/B/C/D、宽硬门槛和产品证据，输出全部通过项目的版本化清单；不负责判断凸性线索。

第二阶段“凸性跟踪”读取第一阶段清单，负责成交、流动性、标准卖出报价、地址、供应、产品使用、风险、四条强路径、活跃项目、凸性线索、动态贝叶斯证据和重要变化。

第一阶段决定谁进入观察范围，第二阶段决定进入后发生了什么。

## 4. 连接但不耦合

- 产品只保留一个 Windows 后台调度器，内部运行两个独立、可恢复任务。
- 两个任务拥有独立游标、断点、状态、失败来源和重试入口。
- 新币筛选失败时，凸性跟踪继续使用上一份完整候选清单。
- 凸性跟踪失败时，前台继续使用上一份完整跟踪结果。
- 两个模块通过稳定资产 ID 和版本化快照交接，不直接修改对方中间数据。
- 任一任务失败都不得发布半份快照或让项目静默消失。

## 5. 更新中心

更新中心继续保持“90 天新币筛选”和“凸性跟踪更新”两个独立页面。两个页面可以分别选择仅手动或自动频率，并分别执行立即更新、暂停和失败重试；底层仍由同一个隐藏 Windows 任务按各自到期时间调度，不新增第二个长期任务。

关闭软件或 Codex 后任务继续；关机后停止，重新登录 Windows 后从断点恢复。普通产品路径不得出现控制台黑框。

## 6. 前台分类

生命周期和凸性判断拆成两个维度：

- 生命周期：0—30 天、31—90 天及 A/B/C 项目关系。
- 跟踪状态：凸性线索、活跃项目、观察中、等待首轮跟踪。

“数据受限”不再作为醒目的前台项目分类。接口额度、来源和程序错误进入后台；前台保留上次完整结果和数据时间。没有可靠数据的字段不显示、不补零、不生成判断。

全部通过宽硬门槛的 A/B/C 项目继续进入“全部机会”，不能因为尚未形成凸性线索而消失。

## 7. 项目详情

统一详情必须包含身份与 T0、筛选通过原因、产品证据、市场和流动性历史、地址和供应、贝叶斯因子与可信度、四条强路径、支持与反证、当前状态、重要变化、来源和数据截止时间。程序不使用模板文字补齐缺失内容。

## 8. 贝叶斯边界

C2.2 按链和真实日龄建立比较组先验，新观测进入后更新项目后验；短历史更接近先验，数据增加后更多反映项目自身。缺失不写零、不重新分配权重，可信度独立计算，同一输入和规则版本必须得到同一结果。

综合分只用于排序、变化和时间外校准，不能单独产生凸性线索。凸性线索仍至少需要两条强路径且必须包含交易与流动性。

程序保存 7/14/30 天后的证据持续、风险出现和流动性保留结果，但积累足够时间外结果前不能宣传为“越来越准的投资预测模型”，也不自动修改门槛。

## 9. 数据与迁移

- `data/c2.1-pipeline.db` 继续负责新币发现、T0、筛选和游标。
- `data/convexity.db` 继续作为既有凸性主干，C2.2 恢复既有跟踪能力的正常写入。
- 两库正式修改前都必须备份；不清空、不覆盖、不重造历史。
- 不重跑已验收 Gate 0 全量 90 天扫描。
- 前台只读取两个模块生成的完整原子快照。
- 必要的新表或字段必须有明确迁移、回滚和数据所有者。

## 10. 允许替换但必须可回滚

- C2.1 覆盖 C1.9/C2.0 前台的渲染方式。
- 固定加权冒充动态贝叶斯的实现。
- 生命周期和凸性信号混合的五状态。
- 前台醒目的“数据受限”分类。
- 凸性跟踪自动调度已断开但页面仍暗示自动运行的状态。
- 只有筛选检查表的简化详情页。

## 11. 本版本不删除

人工复核历史代码、旧 L0-L5 与投资动作语义、旧快照和旧渲染文件、当前空数据复盘表均只保留或隐藏，不在 C2.2 顺手删除。真正删除必须另行获得用户批准。

## 12. 本版本不做

不新增链、DEX 或付费 API；不调整 C2.1 硬门槛和四路径数值；不迁移 .NET/WebView2；不做移动端；不连接钱包、不自动交易；不用大模型补数据；不宣称全市场覆盖；不自动学习并修改规则门槛。

## 13. 发布底线

编码前建立继承基线；真实证明筛选后继续执行凸性跟踪；两页可以独立更新和恢复；模拟断网、429、5xx 和进程终止；通过正式桌面入口、单实例、窗口恢复和隐藏运行；项目、详情和状态完整对账；贝叶斯可复算；文档、数据库和前台数字一致；全量测试和真实桌面点击全部通过。
