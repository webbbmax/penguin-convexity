# 企鹅投研-凸性｜C2.3 独立终验报告

状态：**38/38 通过，已发布**

## 结论

C2.3 已经通过独立终验，正式桌面快捷方式已从旧 PowerShell＋Edge `--app` 启动器切换为 `.NET 10＋WPF＋WebView2` 容器。本轮没有改动 C2.2 网页业务、评分、阈值、数据库结构、更新频率或后台任务。

已确认的核心结果：

- 正式桌面入口真实打开机会首页，重复打开只激活原窗口。
- 桌面软件不再使用普通 Edge 配置，原有 Edge 和 Chrome 窗口、进程均未被关闭。
- 端口冲突、产品身份不匹配、WebView2 缺失、页面渲染进程失败都有可理解的故障处理；用户层未再出现 `Null`、堆栈或原始 JSON。
- 终止一个本项目 WebView2 渲染进程后，容器自动创建新渲染进程并恢复原页，没有重启候选生产任务。
- 1180×760、1440×900 和最大化真实视口均无整页横向溢出、关键遮挡或不可操作。
- 旧快捷方式回滚已真实演练：只恢复入口指向，不回滚网页、数据库、快照或后台任务；演练后已重新切回 C2.3。
