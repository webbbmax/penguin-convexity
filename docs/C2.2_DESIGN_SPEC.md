# 企鹅投研-凸性｜C2.2 桌面设计与交互规格

状态：正式冻结  
范围：现有 Windows 桌面产品，不含手机、平板和移动端适配

## 1. 设计继承

- Logo、南极蓝视觉和口号“洞见共识之外的价值”保持。
- 前台继续四个顶级导航；项目详情继续是上下文页面。
- 后台继续浅色壳和七个栏目，版本号只在后台左栏底部显示一次。
- 不重做桌面容器，不增加新的前台壳或第二套导航。

## 2. 机会首页

- 首屏先回答：当前有多少合格项目、多少凸性线索、多少活跃项目、数据截止到何时。
- 生命周期和跟踪状态分开显示，不把年龄标签排列成质量等级。
- “今天先看”最多 8 个真实项目；只要有合格项目就不得因凸性线索为 0 而显示空页。
- 卡片同时显示日龄段、A/B/C、跟踪状态、主要支持、主要反证和数据时间。

## 3. 全部机会

- 默认“全部”，20 条分页。
- 生命周期筛选与跟踪状态筛选分开。
- “等待首轮跟踪”是正常流程状态，不使用红色错误样式。
- 后台来源错误不生成前台“数据受限”徽标。

## 4. 项目详情

详情采用一页分区，不新增顶级导航：

1. 身份、T0 与筛选结论。
2. 当前跟踪状态、支持和反证。
3. 市场、流动性与退出。
4. 地址、供应、产品使用和风险。
5. 贝叶斯因子与可信度。
6. 四路径和重要变化。
7. 来源与数据时间。

首屏必须先讲清“为什么进入”和“当前为什么处于这个状态”，完整公式和来源按需展开。

## 5. 更新中心

- “90 天新币筛选”和“凸性跟踪更新”是两个独立页面，不把按钮、进度和失败明细挤回同一页。
- 两页均显示自身频率、暂停状态、当前阶段、最近心跳、最近完成、失败范围和重试入口。
- 页面可互相跳转，但操作只影响当前作业；调整一个作业的频率不得悄悄修改另一个。
- 后台明确说明底层只有一个 Windows 调度任务，避免用户误以为两个页面就是两个进程。
- 普通路径不显示黑框；长任务离开页面后继续。

## 6. 失败与空状态

- 前台业务空状态说明“当前没有形成相应线索”，不显示接口错误。
- 后台错误按额度、来源、配置、程序和不支持分类，并给出影响对象和最后成功时间。
- 前台无首轮跟踪数据时只显示筛选事实和“等待首轮跟踪”，不生成假的市场、风险或贝叶斯内容。
- 继续使用上一份结果时显示数据截止时间，不把旧数据写成刚更新。

## 7. 桌面验收视口

1180×760 和 1440×900/最大化必须显示同一核心判断，无整页横向滚动、关键字段遮挡或不可达操作。不开发或验收 375、390、768 等移动视口。
