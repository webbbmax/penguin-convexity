# Gate 0 DEX 90 天回扫状态

更新时间：2026-08-05 14:31（Asia/Shanghai）

## 结论

五条 EVM 链上全部**已登记创建事件结构**已完成历史回扫：18 个 DEX 产品标签对应 16 个物理扫描单元，16/16 完整。累计保留 1,802,896 条创建事件，归并为 1,496,844 个链上唯一候选代币标识。

Solana 7/7 个观察 DEX 标签的 13 种创建指令已实现确定性解码，并完成 SQD 旧归档当前可用约 29 天来源窗口的全量回扫：保留 1,076,032 条创建事件，归并为 953,165 个链上唯一候选代币标识。解码失败、事件重复、候选重复、缺池和缺代币均为 0。

Gate 0 仍未通过。当前观察清单共 43 个 DEX 标签，其中 EVM 36 个、Solana 7 个。EVM 仍有 Ethereum 4、Base 8、Arbitrum 6，共 18 个标签没有确定性创建事件结构；Solana 的解码器和已接受 29 天运行已经完成，90 天起点也已实测可读，但完整 90 天运行仍在后台执行、尚未通过全文件校验。项目身份、安全、交易参与、流动性、钱包结构和动态评分输入也尚未完成全量可用性验证。

因此，六条链合计 2,450,009 个候选只是已覆盖创建事件母池，不是“靠谱新项目”、不是“凸性线索”，也不能冒充全市场 T0。来源区间完整、已登记结构完整和 Gate 0 整体通过是三个不同结论。
