## 已实现

- 前台机会中心改为浅色、只读、普通用户语言，固定四个入口：机会首页、全部机会、重要变化、我们如何判断。
- 首页只保留判断、接近行动的机会、重要变化和当前限制；首页列表有明确上限，全部机会与重要变化使用 20 条分页，不使用无限下拉。
- 项目详情改为上下文页面，只能从机会卡片或变化卡片进入；返回会恢复来源页、筛选、页码和滚动位置。
- 后台所有页面统一为浅色左侧工作台，归入七个一级分组；桌面壳只负责窗口和 iframe 页面切换，不再重复显示第三套导航。
- 工作台和更新中心加入七阶段真实进度、工作单元计数、当前活动、开始时间、耗时、最近心跳、可靠时才显示 ETA，以及部分完成、失败、可能卡住和外部等待的区分。
- C1.9 只在后台左侧栏底部显示一次；前台、详情页、桌面壳和普通正文不显示版本号。
- 新增路由角色清单、改版前哈希/数据库基线、截图清单和 C1.9 专用自测脚本。
