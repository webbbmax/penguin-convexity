# 企鹅投研-凸性｜C2.2 动态贝叶斯证据规格

状态：正式冻结  
用途：排序、变化检测和时间外校准，不直接定义凸性线索

## 1. 模型性质

C2.2 实现确定性的分层正态经验贝叶斯证据收缩。它估计“当前可观测证据在同链同日龄比较组中的相对强弱”，不是收益率、成功率或价格上涨概率模型。

## 2. 比较组

年龄组继续使用：0—2、3—6、7—13、14—30、31—90 天。

比较组优先级继续继承 C2.1：最近 30 天同链同日龄至少 20 个有效对象；不足时使用同日龄六链至少 50 个有效对象；仍不足时使用冻结后备基线。项目只能和真实日龄组比较，不设置年龄加分或扣分。

## 3. 固定输入

| 因子 | 总权重 | 固定指标 |
|---|---:|---|
| D 交易需求 | 25% | 成交额、交易笔数、成交额/流动性、真实买卖活动 |
| L 流动性与退出 | 25% | 流动性相对同组、标准卖出损失反向值、流动性保留 |
| S 持币与供应 | 20% | 前十集中度反向值、HHI反向值、净供应减少 |
| G 活动与估值 | 15% | 产品使用增长、相对扩张、风险修正剩余 |
| Q 稳定性与异常 | 15% | 严重异常反向值、跨来源一致性、活动集中度反向值 |

指标列表和因子总权重固定。缺失指标保留中性先验和“无实测”标记，不把剩余权重重新分配给其他指标。

## 4. 指标预处理

1. 金额、计数和正比率使用 `ln(1+x)`；0—1 比例先限制到 `[0.01,0.99]` 再使用 logit。
2. 同比较组按 P1/P99 截尾，极端值不得无限支配结果。
3. 按指标正负方向转换为同组百分位 `p`，越有利的证据越接近 1。
4. `p` 限制到 `[0.01,0.99]`，转换为 `z=ln(p/(1-p))`。
5. 来源失败、额度受限、配置缺失、程序失败、单位冲突和不可比窗口不产生观测。

## 5. 经验先验

每个指标、链和日龄组使用有效比较对象的稳健中心和离散度建立先验：

```text
theta ~ Normal(mu0, tau0^2)
mu0 = median(cohort_z)
tau0 = max(1.4826 * MAD(cohort_z), 0.50)
```

比较组不足并使用后备基线时，`mu0=0`、`tau0=1`，同时标记 `priorSource=fallback`。先验不能冒充项目实测。

## 6. 新观测更新

每个已完成、定义一致的真实窗口提供一次观测 `z_t`：

```text
z_t ~ Normal(theta, 1 / w_t)
w_t = 1.0  健康且有独立交叉来源
w_t = 0.5  单一可靠来源或非关键降级但数值仍可比较
w_t = 0    缺失、过期、冲突、失败、不支持或单位不稳定

posterior_precision = 1/tau0^2 + sum(w_t)
posterior_mean = (mu0/tau0^2 + sum(w_t*z_t)) / posterior_precision
posterior_variance = 1 / posterior_precision
posterior_score = 100 * logistic(posterior_mean)
```

新窗口只允许追加一次；同一指标、资产、窗口和规则版本必须用唯一键去重，重复调度不能重复增加证据。

短历史项目因有效观测少而自然更接近先验，这不是年龄权重。未来日期不生成观测、不写零。

## 7. 因子与总分

- 每个因子内的固定指标等权组合其后验均值；没有实测的指标仍保留中性先验，不把权重转给其他指标。
- 五因子按 D25%、L25%、S20%、G15%、Q15%形成后台总证据分。
- 总分必须同时保存 80% 后验区间、实测指标数、有效窗口数、先验来源和规则版本。
- 前台不显示总分，只显示因子方向、主要证据、反证和独立可信度。

## 8. 方向变化

方向比较当前与上一份完整后验。设差值服从均值差、方差和的正态分布：

- `P(当前>上一期) >= 0.80`：改善。
- `P(当前>上一期) <= 0.20`：减弱。
- 其余：稳定。
- 没有任何实测指标：尚无实测。

同一窗口重复运行不得产生方向变化。

## 9. 独立可信度

可信度继续独立计算：字段覆盖 35%、数据时效 25%、真实历史覆盖 20%、跨来源一致性 20%。可信度不与后验分数合并，不把来源失败写成项目证据下降。

## 10. 强路径优先

贝叶斯总分、单因子后验或可信度都不能直接形成凸性线索。凸性线索资格继续完全使用 C2.1 冻结四路径、两条强路径、交易与流动性必选、独立来源和异常护栏。

## 11. 时间外校准

C2.2 保存每次完整评估时的后验、区间、输入窗口和规则版本，并在第 7/14/30 天记录：

- 硬门槛是否保留。
- 流动性是否仍高于对应护栏。
- 强路径是否持续或形成。
- 是否后来发现硬风险。
- 产品证据是否升级或失效。

校准报告只比较证据分组与上述结果的持续性和风险识别，不使用代币收益率作为成功标签。单一目标少于 30 个时间外结果时固定显示“样本不足”，不得给出准确率结论。

校准只生成只读报告，不自动修改先验、权重、门槛、强路径或状态。任何参数调整属于以后版本，需用户重新冻结。

## 12. 可复算要求

- 所有输入必须保存来源、时间、单位、转换值、比较组和内容哈希。
- 同一输入、规则版本和截止时间的后验、区间、方向、可信度与总分必须逐位一致或满足冻结浮点容差 `1e-9`。
- 不允许大模型、随机种子、当前页面时间或数组不稳定顺序参与计算。
