## 2. 固定实现顺序

### M1 候选母池生产化

- 只读复用 Gate 0 已验收分片、哈希和最后游标，不重跑已完成90天区间。
- 新增独立 `data/c2.1-pipeline.db`；`data/convexity.db` 首版保持只读。
- 完成事件归并、旧资产/包装/桥接排除、T0证据、A/B/C/D和来源状态。
- 先完成分片、原子检查点、单实例、恢复游标和可见进度，再启动任何超过15分钟的首次转换或深采任务。

### M2 宽硬门槛与规则

- 完成买卖事实、产品证据、显性风险和全部宽硬门槛。
- 按冻结规则配置实现五因子、四条强路径、活跃项目、五状态、可信度和防抖。
- 缺失、无数据、额度、来源失败、不支持、配置缺失和程序失败分别保存。
- 先复算冻结回归清单，再运行接入范围内全部合资格对象；不得用49个固定样本替代正式运行。

### M3 Windows桌面前后台

- 沿用现有四个前台导航和项目详情上下文页，不增加第五个前台顶级栏目。
- 使用现有后台七个一级栏目；C2.1运行、来源、规则和进度进入已有相应管理页面，不在前台显示管理控件。
- 完成隐藏增量任务、手动/自动同流水线、用户频率控制、原子快照和失败回退。
- 只开发Windows桌面路径；不开发手机、平板、移动响应式断点或移动发布包。

## 3. 长任务规则

- 首次生产化和高成本深采由独立Python进程执行，模型任务不得承载网络扫描本身。
- 必须具备分片、断点、原子游标、单实例锁和用户可读进度。
- 是否在对话中持续等待由用户决定；不得因任务仍运行而重复启动或从头重跑。
- 正式桌面路径通过隐藏Windows任务与 `wscript.exe` 启动，黑框次数为0。
- 关闭产品窗口或Codex后任务继续；关机后在下一次Windows登录时从最后提交游标恢复。
