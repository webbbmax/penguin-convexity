# 企鹅投研-凸性｜C2.5 独立验收计划

状态：正式冻结  
执行阶段：只有开发形成固定候选后，才开始独立终验。

## A. 冻结与候选

- A01：C2.5 需求锁及全部正式文件哈希匹配。
- A02：C2.4、C2.3、C2.2、D0 继承依赖哈希匹配。
- A03：候选提交固定，工作区无未解释改动。
- A04：要求 → 实现 → 测试 → 证据追踪表完整。
- A05：正式数据库、凭据、运行状态未进入 worktree 或提交。

## B. 任务登记 Tier 0

- B01：独立枚举已安装 Penguin Windows 任务。
- B02：独立解析主任务 Action 和隐藏 VBS 实际下游。
- B03：独立枚举生产服务 POST 接口。
- B04：独立枚举 21 个 `TASK_DEFINITIONS`，数量和 ID 完全一致。
- B05：独立枚举现役编排器、候选队列、维护和启动任务。
- B06：现场入口与任务账本遗漏 0、重复 0。
- B07：`PenguinConvexity-C1.8-Scheduler` 同时显示机器名和当前中文角色。
- B08：Gate 0 显示已停用，无启用/运行按钮。
- B09：C1.8、C2.1 显示仍可执行和不属于当前自动主干。
- B10：21 个按需任务逐项可见，现役内部组件与旧任务分开。

## C. 状态真实性 Tier 0

- C01：运行状态需要进程/锁和有效心跳。
- C02：历史 `running` 缺少依据时显示陈旧。
- C03：Windows `267009/0x41301` 只解释为计划任务仍运行。
- C04：Windows 下一次检查与作业下次到期分开。
- C05：状态时间、数据时间、快照时间和页面读取时间分开。
- C06：未知总量不显示 0% 或假百分比。
- C07：成功、部分成功、失败和真实零分开。
- C08：一个来源失败只显示真实影响范围。

## D. 控制安全 Tier 0/1

- D01：立即运行先预览再确认。
- D02：重复 `requestId` 不重复启动。
- D03：确认令牌过期或重复使用被拒绝。
- D04：预览后状态改变时执行被拒绝。
- D05：已有运行锁时不启动第二写入者。
- D06：安全暂停先显示请求，只有到检查点才显示暂停。
- D07：暂停筛选后续周期不暂停跟踪或 Windows 调度器。
- D08：频率只允许 1/3/6/12/24 小时并权威回读。
- D09：来源重试只能使用对应任务已登记来源。
- D10：分片重试只能使用存在且合法的分片。
- D11：历史候选无“从头运行”。
- D12：Gate 0、旧 C1.8/C2.1 和未签安全合同工具无误导控制。
- D13：失败操作保持原状态并留下审计。
- D14：批量操作逐项显示任务、顺序和影响。

## E. 规则透明 Tier 1

- E01：C2.4 冻结规则哈希和版本正确。
- E02：活动试行文件哈希、状态和批准时间正确。
- E03：15%、20%、10% 基线值完整显示。
- E04：报价成功即可的活动覆盖与基线差异完整显示。
- E05：六组停用门槛仍保存原始证据且页面无空值。
- E06：代码有效值与页面有效值逐项一致。
- E07：基线和有效规则使用同一输入重放。
- E08：影响数量和 `assetId` 集合差异独立复算一致。
- E09：真实通过和未通过样本可追溯；无样本如实显示。
- E10：任一 `assetId` 可追到证据、时间、规则、覆盖、状态和快照。
- E11：贝叶斯不被解释为资格或凸性线索。
- E12：未批准/过期/损坏覆盖不静默生效。

## F. 页面与继承 Tier 2

- F01：管理者总览十秒内回答任务、健康、变化、下一次和可操作项。
- F02：全部任务筛选不默认隐藏失败、停用和旧版。
- F03：六类任务详情使用独立稳定承载。
- F04：逐链 × 来源健康可下钻。
- F05：规则透明、项目判定、快照交接、运行审计均可达。
- F06：运行记录与管理审计分开。
- F07：旧记录显式标记版本与陈旧。
- F08：C2.4 29 个既有路由逐项返回正确内容。
- F09：批准删除 0，替代入口均有可达后继。
- F10：普通用户前台无任务、调度、日志或管理控制。
- F11：项目详情返回原筛选、页码和滚动。
- F12：RWA 运行资产引用 0。

## G. 数据与快照 Tier 2

- G01：两库只读 `quick_check=ok`。
- G02：外键异常 0。
- G03：快照生产者、消费者、对象数、数据时间和校验完整。
- G04：生命周期与凸性跟踪状态分开。
- G05：页面组合状态不写业务数据库。
- G06：管理审计不作为任务状态源。
- G07：上一份完整快照在失败时保留并标记陈旧。
- G08：没有第二调度器、第二 C# 业务通道或第二任务真相。

## H. 整体设计系统 Tier 3

- H01：企鹅 Logo、口号和南极蓝品牌保持。
- H02：全产品设计令牌唯一，无未登记按钮/进度/弹窗样式。
- H03：普通、悬停、按下、焦点、加载、禁用和失败按钮截图通过。
- H04：瞬时、短时、确定进度、未知进度、暂停、部分完成和失败截图通过。
- H05：普通通知、高影响确认、字段错误、全局错误和空状态通过。
- H06：图表有口径、时间、筛选和精确表格。

## I. Windows 真实桌面 Tier 3

- I01：1180×760 冷启动和主路径。
- I02：1440×900/最大化主路径。
- I03：Windows 100%、125%、150% DPI。
- I04：左键、右键、悬停、滚轮和文本复制。

- I06：最小化、最大化/还原、关闭、拖动、调整大小和贴靠。

## J. 审计与恢复

- J01：每次高影响预览和执行都有审计。
- J02：审计包含前后值、影响、确认、运行和结果。
- J03：审计不含密钥、令牌正文或敏感响应。
- J04：频率/暂停可回滚至明确前值。
- J05：规则覆盖可回滚至明确版本且不删除历史证据。
- J06：控制失败、服务重启和页面重开后状态仍可恢复。
- J07：临时产物登记、封存和到期阻断检查通过。

## K. 发布阻断

以下任一发生均不得发布：

- 任务遗漏或重复。
- 规则空值、有效规则与代码不一致。
- 页面状态冒充真实运行。
- 控制绕过预览、幂等、锁或安全检查点。
- Gate 0/459 万重跑能力暴露。
- 29 路由删除或普通前台出现管理控件。
- 正式数据库被测试写入。
- Apple 视觉导致 Windows 操作异常。
- 低优先级通过数掩盖 Tier 0/1 失败。

## L. 发布前后

独立终验通过后仍需用户明确发布授权。发布前执行 D0 `release_preflight`，核对固定候选、回滚点、真实桌面、数据边界和授权；发布后核对正式标签、本地 main、远端和正式桌面入口。发布失败只回滚代码与入口，不覆盖正式数据库或用户设置。
