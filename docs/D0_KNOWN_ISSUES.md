# D0 重建基线已知问题

D0 保存的是 2026-08-14 正在运行的 C2.4 事实，不是“业务已经全部正确”的证明。下列问题被明确保留，不能因代码进入干净提交而视为解决：

1. 六条链的现实覆盖与程序筛选结果仍需逐链核对，Robinhood 和 Solana 是已被用户明确指出的异常样本，其余链也不能按统一修复自动判定正常。
2. 90 天候选、第一关、凸性跟踪和机会中心之间虽然已有 C2.4 合同，但真实数量、交接完整性和前台可见结果仍需在后续业务版本按 `assetId` 独立对账。
3. 管理者目前不能在一个控制面完整看到所有后台作业、逐链来源、自动/手动控制和规则淘汰原因；D0 只把“不得隐藏后台任务”写入开发流程，不新增产品 UI。
4. 当前公开结果过少、活跃项目或凸性线索为零，不得仅凭门槛解释；后续必须先排除发现覆盖、接口、链归属、交接和任务完成度问题，再讨论放宽规则。
5. 本清单不授权 C2.5，也不授权修改六链接口、第一关、第二关、四路径、贝叶斯、页面或数据库。

后续每个业务版本必须从本清单选择明确问题，形成新的大白话冻结稿；未被选择的问题继续保留，不得静默标记完成。
