## 终验发现并修复的核心问题

### 1. 动态比较组实际上没有生效

四条强证据路径原先虽然显示 P50/P40，但运行时始终使用固定后备阈值；真实数值为 0 时还会被当成“缺失”替换。这会让路径判断和冻结规则不一致。

现已改为：优先使用同链、同日龄、近 30 天比较组；样本不足时使用六链同日龄近 30 天；仍不足才使用固定后备值。快照同时记录实际比较组、样本量和实际阈值。独立审计没有导入实现的资格函数，重新计算后比较组不一致为 0。

### 2. 第三方脚本链接被误当成项目官方 GitHub

原采集会扫描官网原始 HTML，导致脚本或依赖说明中的 GitHub 地址被误认为项目仓库；GitHub 个人主页还会被扩展为最近更新的任意仓库。真实桌面点击已经打开过与项目无关的仓库，因此这是公开资格错误，不是文字体验问题。

现只接受官网可点击的明确 `owner/repository` 链接；脚本内 URL、个人主页和不能归属到项目的仓库不再合格。已复核 38 个官网映射，撤回 15 个无明确仓库映射和 2 个受影响公开项目；逐行修复前数据保存在可恢复备份中。
